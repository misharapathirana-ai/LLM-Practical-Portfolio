# LLM Practical Portfolio

PUSL3205 Large Language Models and Generative AI

Author: Mishara Pathirana

This repository contains my laboratory work for the module, one folder per lab with its own README (objective, implementation, results, observations and learning outcomes).

## Labs

| Lab | Topic | What it covers |
|---|---|---|
| [Lab 01](Lab-01-Machine-Learning/README.md) | Sentiment analysis with traditional machine learning | Text preprocessing, Bag-of-Words, Logistic Regression and SVM, about 80% accuracy |
| [Lab 02](Lab-02-LLM-Everyday-Life/README.md) | LLMs in everyday life | LightLoad, a product concept and app mock-up for the overloaded student, developed with an LLM |
| [Lab 03](Lab-03-Tiny-Transformer/README.md) | Tiny Transformer | A GPT-style model built from scratch in PyTorch and trained on TinyStories (10.8M parameters) |
| [Lab 04](Lab-04-Fine-Tune/README.md) | Fine-tuning with LoRA | Qwen2.5-0.5B fine-tuned on a small shop dataset and compared with the original model |
| [Lab 05](Lab-05-RAG-Pipeline/README.md) | RAG pipeline | Local retrieval-augmented generation with Llama 3.2 3B, ChromaDB and a Streamlit chat with PDF upload |
| [Lab 06](Lab-06-AI-Agents/README.md) | AI agents | A tool-using agent with six tools, SQLite memory, a RAG tool and Google Calendar |

[Final reflection](Final-Reflection.md)

## Notes
- Datasets, model weights, vector databases and login files are not included in the repository. Each lab README says how to download or create them.
- Labs 03 and 04 were run on Google Colab (T4 GPU). Labs 01, 05 and 06 were run on a Windows laptop.
